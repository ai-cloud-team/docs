# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

`docs` — документация ai-cloud-team для пользователей и операторов (Mintlify). Репозиторий private до решения владельца о публикации; черновики страниц готовятся в `research-local/public-drafts/docs/` и переносятся сюда только по явному «публикуем». Аудитория: человек, который получил ассистента в Telegram, и оператор, который хочет поднять свою инсталляцию. Внутренние PRD, решения и планы здесь не публикуются — они в `platform/docs/` (private).

## Разделы (целевые)

Getting started · Talking to your assistant (что он понимает, уточняющие вопросы, кнопки, `/cost`, `/profile`) · Budgets & safety (бюджеты, TOTP step-up, что ассистент никогда не делает сам: платежи, бронирования, письма третьим лицам) · Self-hosting (EKS, Flux, ESO, чарт `act-tenant`, репо `tenants`) · FAQ · Changelog.

## Правила

- Писать от лица пользователя, а не системы: «вы задаёте задачу», не «TaskSpec формируется». Термины без русского эквивалента оставлять английскими.
- Не раскрывать детали, которых нет в публичном чарте: внутренние адреса, структуру ASM, правила NetworkPolicy сверх того, что нужно оператору.
- Каждая страница о команде бота содержит пример диалога.
- Английский — основной язык публичной документации; русская версия — `ru/` тем же деревом.

## Фреймворк

Mintlify (решение #5, утверждено 2026-08-29): `docs.json` — навигация, MDX-страницы в корне и `faq/`. Frontmatter каждой страницы: `title`, `description`. Компоненты Mintlify (`<Steps>`, `<Note>`, `<Tabs>`) — по необходимости. Сайт публикует Mintlify через GitHub App из `main` — подключается после решения о публикации.

## Команды

- CLI: `npm i -g mint`; локально из каталога с `docs.json`: `mint dev`; обновить CLI: `mint update`.
